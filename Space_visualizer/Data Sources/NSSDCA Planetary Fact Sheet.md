# NSSDCA Planetary Fact Sheet

Back to [[Home]]

- **Publisher:** NASA Goddard Space Flight Center, NSSDCA (D. R. Williams)
- **URL:** https://nssdc.gsfc.nasa.gov/planetary/factsheet/
- **Used for:** Planet physical and orbital facts (mass, diameter, density, gravity, rotation, distances, period, temperature, pressure, moons, rings, magnetic field).
- **Accuracy / caveats:** Values are rounded. "Unknown" entries (for example giant-planet surface pressure) are omitted rather than shown. Negative rotation periods mean retrograde rotation. Moon counts change as discoveries are confirmed.
- **License:** NASA public domain
- **How it is refreshed:** `npm run data`
- **Parsed by:** `pipeline/sources/nssdcFactSheet.ts`
